# C8.3: release reliability (after Windows acceptance)

1. **Single-instance GUI**: use `QLocalServer`/`QLocalSocket` so a second Start
   Menu click activates the existing tray-hidden GUI rather than creating
   another. Keep this *separate* from the existing background mutex.
2. **Updater lifecycle**: ensure the agent and GUI are stopped before upgrades
   and their startup paths are revalidated after installation. Verify the
   `--stop-agent` handshake across normal, interrupted and pre-C8.2 versions.
3. **Migration/backup**: add atomic versioned backups for the SQLite catalogue,
   per-user JSON and QSettings values; test schema upgrades with rollback.
   Never remove original wallpaper files.
4. **Windows CI**: build/check Nuitka and Inno artifacts on Windows runners.
   Add a real headless agent launch test on a disposable test profile.
5. **Releases**: create versioned portable ZIP and installer EXE, documented
   SHA-256 checksums, GitHub Releases, reproducible dependency pins and changelog.
6. **Upgrade matrix**: clean Windows, fresh non-admin user, spaces in paths,
   older installations, duplicate processes, connected/disconnected monitors,
   startup after reboot, Defender/SmartScreen prompts and uninstall/reinstall.
7. **Better errors**: in-app diagnostics export with redacted logs, actionable
   explanations and an opt-in reporting workflow.

C9 remains cross-platform wallpaper backends and a more approachable GUI/UX.
